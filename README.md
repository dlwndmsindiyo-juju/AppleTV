# Apple TV 취향 추천 데이터 — 96개 조합

확인일: 2026-10-30 · 대상: https://tv.apple.com/kr

## 결과를 먼저 확인하세요

- 공식 한국 작품 페이지 218개를 조사하고, 선택한 6개 장르와 연결되는 187개 작품을 데이터로 정리했습니다.
- 6개 장르 × 4개 분위기 × 4개 시간 = **96개 조합**, 조합마다 **중복 없는 20개 후보**입니다.
- 1,920개는 목록에 배치된 수이며, 서로 다른 작품 1,920편이라는 뜻이 아닙니다.
- 96개 중 15개 조합은 20개 모두 조건을 충족합니다. 전체 배치 중 689개는 조건 일치, 1,231개는 조건 확장입니다.
- ‘호러 + 따뜻한 갈등 + 30분 이하’처럼 공급이 부족한 조합을 억지로 일치 처리하지 않았습니다. 확장 후보에는 완화한 장르·분위기·시간을 표시했습니다.
- 로맨스+긴장감과 로맨스+따뜻한 갈등은 시간 옵션 4개 모두에서 실제 후보 구성에 차이가 있는지 검증했습니다.

## 파일 구성

1. `INDEX.md`: 96개 목록과 일치/확장 수를 한눈에 보는 목차.
2. `96_lists/`: 각 조합별 작품 20개, 공식 링크, 길이, 회차 링크, 추천 근거.
3. `catalog.json`: 187개 작품의 공식 장르·링크·러닝타임 근거와 편집 분류.
4. `combinations.json`: 96개 × 20개 후보를 프론트엔드에서 바로 읽을 수 있는 데이터.
5. `recommendations.mjs`: 복수 장르·분위기·시간을 동시에 처리하는 순수 JavaScript 추천 함수.
6. `sources.json`: 공식 페이지와 확인 근거 목록.
7. `tests.mjs`: 96개 목록, 시간 조건, 복수 장르, 별칭, 조합별 차이 검증.
8. `excluded.json`: 공개 예정/회차 근거 부족으로 제외한 2개 작품.

| 단계 | 화면 값 | 추천 내부 값 |
|---|---|---|
| 장르 | 코미디 / 호러 / 로맨스 / 스릴러 / SF / 애니메이션 | `preferences.genres`: 문자열 배열 |

기존 팝업 코드의 `가볍게 웃고 싶어요`, `따뜻한 감동`, `상관없어요`도 지원합니다.
화면의 ‘따뜻한 갈등’은 가족·연인 관계의 갈등과 회복, 감정의 여운으로 해석했습니다. 격한 싸움이나 범죄의 긴장을 뜻하는 분류가 아닙니다.

## 시간과 복수 장르 기준

- **30분 이하**: 영화/단편 전체 또는 확인한 실제 회차 중 30분 이하인 회차.
- **1시간 내외**: 영화 또는 실제 회차 40~75분. 이 범위는 추천 구현을 위한 편집 기준이며 `CONFIG`에서 바꿀 수 있습니다.
- **영화 한 편**: `movie`이면서 전체 길이 60분 이상인 작품. 단편과 시리즈는 일치 처리하지 않습니다.
- **상관없음**: 시간 제한을 적용하지 않습니다.
- 시리즈의 확인 회차는 공식 작품 페이지에 노출된 최대 6개입니다. 목록의 해당 회차를 기준으로 판단하며, 전 시즌 모든 회차가 같은 길이라는 뜻이 아닙니다.
- 복수 장르는 기본 **AND**: 로맨스+SF이면 두 장르를 모두 가진 작품만 일치합니다. `genreMode: 'any'`로 바꾸면 OR 방식입니다. 선택 순서는 결과에 영향을 주지 않습니다.
- 빈 분위기는 분위기 제한을 걸지 않습니다. 장르는 반드시 하나 이상 선택해야 합니다.

## 실제 앱에서 사용하기

```js
import catalog from './catalog.json';
import { recommend } from './recommendations.mjs';

const preferences = {
  genres: ['로맨스'],
  mood: '긴장감 넘치는',
  duration: '1시간 내외',
};

// 선택 조건을 모두 충족하는 작품만, 최대 20개.
const exact = recommend(catalog, preferences);

// 사용자가 '조건을 넓혀 보기'를 선택했을 때만 확장 후보 포함.
const candidates = recommend(catalog, preferences, {
  limit: 20,
  includeExpanded: true,
  genreMode: 'all',
});
```

기본 함수는 조건 일치 작품이 부족하면 20개보다 적게 반환합니다. 화면에서 20개를 채우기 위해 확장 후보를 사용한다면 `exactMatch`, `relaxations`, `reason`을 반드시 함께 표시하세요. 다른 시간대 작품을 ‘30분 이하’라고 표기하면 안 됩니다.

`catalog.json`은 작품 정보, `combinations.json`은 준비된 단일 장르 목록입니다. 복수 장르 조합은 `recommend()`에서 계산합니다. JSON을 활용하는 앱에는 별도 API 키가 필요하지 않습니다.

이 압축은 조사 데이터와 재사용 함수입니다. 기존 `MoodAssistant.jsx` 또는 팝업 파일을 덮어쓰는 패치가 아닙니다. 기존 화면에 연결하려면 `onRecommend`의 결과에 `title`, `poster`, `genre`, `overview` 등을 전달하세요. Apple 작품 ID는 TMDB 숫자 ID가 아니므로 `/tv/{id}` 상세 경로에 바로 넣으면 안 됩니다. 외부 이동은 `appleUrl`을 일반 `<a>`의 `href`로 사용하세요.

## 근거와 편집 판단 구분

- **공식 확인 사실**: 작품명, 형식, 공식 장르, 영화 길이, 확인한 회차 길이, 한국 작품 페이지 링크.
- **편집 판단**: `thematicGenres`와 `moodScores`. 분위기는 Apple의 공식 분류가 아닙니다. 공식 소개의 관계·가족·비밀·위협·수사·미래 등 요소와 작품별 보정으로 평가했습니다. `moodScores`는 확률이나 객관적 평가 점수가 아닙니다.
- `officialGenres`와 `genres`를 구분했습니다. 예를 들어 가족을 되찾는 SF 스릴러는 주제상 로맨스로도 연결될 수 있지만, 그것이 Apple의 공식 로맨스 분류라는 뜻은 아닙니다.
- 검증 범위는 한국 공식 작품 페이지입니다. 페이지가 있다는 사실만으로 Apple TV 구독에 포함되거나, 지금 바로 재생·구매·대여할 수 있다고 확정하지 않았습니다. 앱의 ‘시청 가능’ 필터에는 별도의 실시간 제공처 확인이 필요합니다.
- 이미지는 공식 페이지의 원격 URL만 기록했습니다. 사용자가 제공한 `AI_pop_up1~31.png`와 번호로 임의 연결하지 않았습니다. 로컬 이미지를 쓰려면 작품 제목을 대조해 교체하세요.
- 전체 Apple TV 카탈로그를 망라한 목록은 아닙니다. 이번 조사에서 확인한 작품 범위의 후보 목록입니다.
