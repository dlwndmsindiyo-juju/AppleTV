# 🍎 Apple TV OTT Renewal

> **콘텐츠를 발견하는 순간부터 시청과 재방문까지, 더 직관적인 Apple TV 경험을 설계합니다.**

Apple TV의 시네마틱한 브랜드 경험과 미니멀한 디자인을 유지하면서, 콘텐츠 탐색의 복잡성을 줄이고 서비스 이해도와 사용성을 높이기 위한 **웹 UX/UI 리디자인 프로젝트**입니다.

## 01. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | Apple TV OTT Renewal |
| 프로젝트 유형 | OTT 웹사이트 UX/UI 리디자인 |
| 핵심 목표 | 콘텐츠 발견성 향상, 탐색 과정 단축, 시청 흐름 개선 |
| 주요 대상 | 신규 비구독 사용자, 기존 구독 사용자 |
| 디자인 방향 | Cinematic UI · Minimal Design · Intuitive Navigation |

### 프로젝트 목표

- Apple TV 고유의 시네마틱한 감성과 브랜드 정체성을 유지합니다.
- 사용자가 원하는 콘텐츠를 빠르게 발견하도록 정보 구조와 탐색 동선을 개선합니다.
- 구독 전 서비스 이해부터 구독 후 시청·재방문까지 자연스러운 사용자 흐름을 설계합니다.
- 상태 안내와 오류 피드백을 명확히 제공하여 불필요한 이탈을 줄입니다.

## 02. 문제 정의 (Problem)

### 콘텐츠 탐색의 어려움

프로모션 중심의 화면 구성으로 인해 콘텐츠 종류와 탐색 경로를 한눈에 파악하기 어렵습니다. 원하는 작품이나 이어보기 영역에 도달하기까지 불필요한 탐색이 발생할 수 있습니다.

### 서비스 가치 전달 부족

신규 사용자가 구독 전에 콘텐츠의 차별성과 서비스 혜택을 직관적으로 이해하기 어려워 구독 결정을 망설일 수 있습니다.

### 시청 상태 및 오류 안내 부족

회차 정보, 시청 진행률, 구독 필요 여부, 재생 오류 원인 등에 대한 안내가 부족하면 사용자가 다음 행동을 판단하기 어렵습니다.

**핵심 UX 과제:** 사용자가 콘텐츠를 찾고, 이해하고, 시청하기까지의 과정을 단순하고 명확하게 연결하는 것.

## 03. 타깃 사용자 (Persona)

| 구분 | 신규 비구독 탐색 사용자 | 기존 구독 반복 시청 사용자 |
| --- | --- | --- |
| 페르소나 | 김서윤 (29세) | 이준호 (34세) |
| 주요 목표 | 서비스 가치를 이해하고 구독 여부 결정 | 시청 중인 작품을 이어보고 다음 작품 발견 |
| 주요 불편 | 구독 혜택과 작품의 차별성 파악이 어려움 | 이어보기와 후속 콘텐츠 탐색에 시간이 소요됨 |
| UX 대응 | 구독 안내, 콘텐츠 미리보기, 직관적인 서비스 설명 | 이어보기, 진행률 표시, 개인화된 다음 콘텐츠 제안 |

*위 페르소나는 기획을 위해 설정한 대표 사용자 유형입니다.*

## 04. UX/UI 개선 전략 (Solution)

### 1. 시네마틱 그리드 기반 콘텐츠 탐색

- 콘텐츠의 시각적 몰입감을 유지하면서 영역별 정보 위계를 명확히 구성
- 장르·취향 등 다양한 탐색 방식과 필터 제공
- 사용자가 원하는 작품을 빠르게 비교하고 선택할 수 있는 카드형 UI 설계

### 2. 사용자 여정에 따른 화면 구성

- **신규 사용자:** 서비스 소개 → 콘텐츠 탐색 → 구독 플랜 확인 → 구독 결정
- **기존 사용자:** 홈 진입 → 이어보기(Continue) → 다음 콘텐츠 발견(Next Discovery) → 시청

### 3. 로그인 및 이용 접근성 개선

- 이메일 로그인과 간편 로그인으로 접근 경로 단순화
- 국가·지역 설정을 통한 이용 가능 콘텐츠 안내
- 구독 상태 및 이용 제한을 이해하기 쉬운 문구로 제공

### 4. TV+ Assistant 설계

자연어 입력을 통해 취향과 감정에 맞는 콘텐츠 추천, 자주 묻는 질문 안내, 관련 설정 화면으로의 이동을 지원하는 **대화형 어시스턴트 경험**을 제안합니다.

**사용 예시**

- “우울할 때 보기 좋은 영화 추천해줘.”
- “가볍게 볼 수 있는 드라마 알려줘.”
- “결제 수단은 어디서 변경해?”

챗봇을 사용하지 않더라도 기존 검색과 그리드 탐색으로 동일한 주요 목적을 달성할 수 있도록 설계합니다.

## 05. 주요 사용자 플로우 (User Flow)

```text
[신규 사용자]
랜딩 페이지 → 콘텐츠 탐색 → 작품 상세 → 구독 플랜 선택
→ 결제 수단 선택 → 결제 정보 입력 → 구독 확인 → 구독 완료 → 홈

[기존 사용자]
로그인 → 홈 → 이어보기 / 콘텐츠 탐색 → 작품 상세 → 시청

[도움이 필요한 사용자]
챗봇 실행 → 질문 입력 → 추천 또는 FAQ 안내 → 관련 화면 이동
```

## 07. 향후 개선 방향 (Next Steps)

### 선택적으로 호출하는 TV+ Assistant

챗봇은 기본적으로 작은 플로팅 버튼으로 노출하고, 사용자가 필요할 때만 확장하도록 설계하여 메인 콘텐츠의 몰입감을 유지합니다.

### 추천 이유의 투명한 제공

추천 카드에 “최근 시청한 작품과 비슷한 장르”와 같은 짧은 근거를 제공하여 사용자가 추천 결과를 이해하고 선택하도록 돕습니다.

### 상태 피드백과 해결 동선 강화

구독 추가 필요, 재생 실패, 접근 제한 등의 상황에서 원인 안내와 함께 **구독 바로가기**, **다시 시도**, **고객센터 연결** 등의 다음 행동을 명확히 제공합니다.

### 멀티 디바이스 접근성 검증

데스크톱·태블릿·스마트 TV 환경에서 텍스트 대비, 반응형 레이아웃, 포커스 상태, 키보드 및 리모컨 조작 흐름을 검토합니다.
